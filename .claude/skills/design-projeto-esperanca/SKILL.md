# Skill: Design Projeto Esperança

O projeto deve ter aparência acolhedora, limpa, institucional e confiável.

Prioridades visuais:
- Interface clara
- Aparência humana e acolhedora
- Boa hierarquia visual
- Botões visíveis, mas não exagerados
- Login discreto no site público
- Dashboard organizado e funcional
- Cards com espaçamento confortável
- Textos fáceis de ler
- Design responsivo

Não criar estilos aleatórios.

Sempre reutilizar o padrão visual já existente no projeto.
