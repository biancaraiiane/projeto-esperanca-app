# Referências do Projeto Esperança

## Princípios visuais

O projeto deve ter aparência acolhedora, institucional e confiável, combinando com uma ONG.

Prioridades:

- Clareza
- Acessibilidade
- Layout limpo
- Boa hierarquia visual
- Interface amigável
- Visual fiel às imagens enviadas pelo usuário

## Regra de fidelidade

A imagem enviada pelo usuário deve ser tratada como referência visual principal.

Não substituir o design por uma versão "melhorada" sem autorização.

## Login discreto

Quando houver acesso para funcionários/admins no site público, o botão de login deve ser discreto, sem competir com as chamadas principais do site.

## Dashboard administrativo

O dashboard deve manter aparência organizada e funcional.

Possíveis áreas:

- Voluntários
- Parcerias
- FAQ
- Administradores
- Perfil
