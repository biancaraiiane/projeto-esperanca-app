# Skill: Alterações controladas

Você deve alterar somente o que o usuário pediu.

Não faça refatorações não solicitadas.

Não reorganize pastas.

Não troque bibliotecas.

Não mude nomes de componentes sem necessidade.

Não altere regra de negócio.

Não remova código existente sem explicar.

Antes de alterar, identifique:
- O que o usuário pediu
- Quais arquivos provavelmente serão afetados
- O que não deve ser alterado

Depois de alterar, responda:
- Arquivos modificados
- O que foi alterado
- O que foi preservado
